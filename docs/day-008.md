# День 008 — план: перехід з RP2040 на RP2350 (Pico 2)

**Дата плану:** 2026-10-23. **Гілка:** `with-rp-2350` (RP2040-версія лишається в `with-probe-rs`).

**Стан на початок:** коміт `56460d4` (день 007: рядок по USB лише при DTR). Прошивка на embassy-rp 0.10, чип RP2040
(RP2040-Zero).

> **Мета дня.** Та сама прошивка ESC (DShot300 bidir + EDT, USB-рядок, defmt) працює на **Raspberry Pi Pico 2**
> (RP2350A, ядра **Cortex-M33**). RP2040 у цій гілці більше не підтримуємо: не feature-перемикач, а заміна.
> Поведінка DShot (PIO-програма, такти, відповіді, EDT) не змінюється.
> Прошиваємо **лише через пробник** (probe-rs); шлях BOOTSEL/UF2 не підтримуємо.

## 1. Вибір

| Що | Вибрано | Чому |
|---|---|---|
| плата | Raspberry Pi Pico 2 | RP2350A (QFN-60), 4 МБ flash, SWD-роз'єм під Debug Probe |
| ядро | Cortex-M33, target `thumbv8m.main-none-eabihf` | probe-rs + defmt як і було; апаратний FPU для `f32` (`hf`); у embassy-rp це основний шлях. Hazard3 (RISC-V, `riscv32imac`) не має FPU і слабше підтримується |
| RP2040 | прибрати з цієї гілки | одна конфігурація, без двох `memory.x` і двох target |

## 2. Що змінюється

| Файл | RP2040 (зараз) | RP2350 (стане) |
|---|---|---|
| `Cargo.toml` | `embassy-rp` feature `rp2040` | `rp235xa` (Pico 2 — RP2350A) |
| `.cargo/config.toml` | target `thumbv6m-none-eabi`; `-Tlink-rp.x` (boot2); `no-vectorize-loops` | `thumbv8m.main-none-eabihf`; без `-Tlink-rp.x` і без `no-vectorize-loops` |
| runner | `probe-rs run --chip RP2040` | `probe-rs run --chip RP235x` |
| `memory.x` | `BOOT2` 256 Б + `FLASH` 2 МБ, `RAM` 264 КБ | `FLASH` 4 МБ від `0x10000000`, `RAM` 512 КБ (+ SRAM4/5 по 4 КБ); секції `.start_block`, `.end_block` |
| завантаження | boot2 з embassy-rp у перших 256 Б | boot2 немає: boot ROM шукає блок **IMAGE_DEF** у перших 4 КБ flash; embassy-rp кладе його сам (`ImageDef::secure_exe()` за замовчуванням) у `.start_block` |
| `src/main.rs` | — | код без змін; лише коментарі про такти й стартовий рядок defmt |

Пробна збірка вже зроблена: `cargo build --release` проходить, `.start_block` на `0x10000114` (20 байт,
маркери `0xffffded3` … `0xab123579`), clippy і `cargo fmt --check` чисті, тести codec 23 / esc-emu 10.

### Такти PIO

| | RP2040 | RP2350 |
|---|---|---|
| clk_sys (embassy-rp за замовчуванням) | 12 МГц × 125 / 6 / 2 = **125 МГц** | 12 МГц × 125 / 5 / 2 = **150 МГц** |
| дільник 12 МГц | 10,4167 → `0xA6B` (16.8) | **12,5 → `0xC80`**, рівно |
| такт PIO | 11 998 500 Гц (−125 ppm) | **12 000 000 Гц** |
| біт команди / біт відповіді | 40 / 32 такти | без змін: 40 / 32 такти |

Дільник рахується з `clk_sys_freq()`, тож код не змінюється; похибка такту зникає.

### На що звернути увагу

| Що | Чим загрожує | Що з цим |
|---|---|---|
| ерата RP2350-E9 (витік струму входу, «залипання» ніжки ≈ 2 В при pull-**down**) | хибні рівні на вході | у нас **pull-up** на GPIO0, лінію тягне FC; E9 стосується насамперед pull-down. Якщо побачимо `bad` — мультиметром рівень GP0 без кадрів (FC вимкнений): має бути ≈ 3,3 В |
| ізоляція падів (`ISO`) на RP2350 | ніжка не працює після скидання | `make_pio_pin` в embassy-rp знімає `ISO` і вмикає `IE` |
| входи без `IE` за замовчуванням | PIO не бачить лінію | те саме, `make_pio_pin` |
| `probe-rs reset --chip RP2040` в AGENTS.md / README | інша назва чипа | `--chip RP235x` |
| `sweep_cli.py`, `hil/*` | шукають порт за VID `c0de` | VID/PID USB не змінюємо — працюють як були |

## 3. Підключення Pico 2

| Pico 2 | Куди |
|---|---|
| GP0 (фізичний пін 1) | сигнальна лінія DShot (через резистор, як було, `docs/series-resistor.md`) |
| GND (пін 3) | GND FC / стенда |
| GP3 (пін 5) | debug-вихід для аналізатора; аналізатора поки немає — не підключаємо |
| роз'єм DEBUG (SWCLK, GND, SWDIO) | Raspberry Pi Debug Probe |
| micro-USB | ПК: CDC `DShot logger` (`c0de:cafe`) |

## 6. Якщо щось не так

| Симптом | Що робимо |
|---|---|
| probe-rs прошив, але програма не стартує | IMAGE_DEF: `.start_block` має бути в перших 4 КБ (дивимось адреси секцій в ELF) |
| `probe-rs` не бачить чип | SWD-роз'єм Pico 2, живлення від USB; `probe-rs list` |
| PIO не приймає кадри (`n=0`) | ніжка GP0: `ISO`/`IE`, pull-up; проводи і GND; мультиметр на GP0 |
| `bad` росте або лінія в спокої не 3,3 В | ерата E9 — див. п. 2; перевірити рівень у паузі |
| USB-порт не з'являється | дивимось defmt; USB-PLL у embassy-rp для RP2350 той самий (48 МГц) |
