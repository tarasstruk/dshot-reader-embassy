# 005 — більше телеметрії EDT: результати стенда

**Дата:** 2026-10-18. **Гілка:** `with-probe-rs`. **Прошивка:** коміт `4c4014a` (код — `e023a38`), release, прошита через probe-rs (`flash.log`: 1,82 с, лог старту). **FC:** TBS Lucid, Betaflight 2026.6.2, `dshot_edt = FORCE`; RP2040 на виході мотора 4.

План дня — `docs/day-005.md`; як влаштований EDT — `docs/edt.md`.

> **Коротко.**
> - Betaflight приймає всі нові типи EDT: Type **`RTVCS`** (оберти, температура, напруга, струм, status).
> - TEMP, VCC, CURR і ST/EV на всіх п'яти значеннях газу **точно** збігаються з таблицею 2.1 плану; eRPM / RPM — як на етапі C; Invalid 0 %.
> - ST/EV показує байт status десятковим числом: 75 = `0x4B` (warning + stress 11), 206 = `0xCE` (warning + alert + stress 14).
> - Debug доходить: після перезавантаження FC DBG2 = 1 (`late` на RP2040 став 1). DBG1 = 0, бо `bad = 0`. DBG3 = 0 — stress ми не шлемо.

## 3. Debug 1 / Debug 2

Під час прогону `bad = 0` і `late = 0`, тож DBG1 і DBG2 = 0 — з цього не видно, чи вони взагалі доходять. Перевірка: після `exit` FC перезавантажився, на кілька секунд кадри зникли, і RP2040 зарахував одне пізнє пробудження (`late = 1`). Після старту FC — `dshot_telemetry_info`:

```
Motor    Type   eRPM    RPM     Hz Invalid   TEMP    VCC   CURR  ST/EV   DBG1   DBG2   DBG3
    4   RTVCS      0      0      0   0.00%     25  16.75      0      0      0      1      0
```

**DBG2 = 1** — молодший байт `late` доходить до Betaflight. DBG1 = 0 відповідає `bad = 0`; ненульовий DBG1 на стенді не перевірено (немає поганих кадрів), його кодування покривають тести `esc-emu` (`edt_every_32nd_reply_in_turn`). Після цього FC знову перезавантажився (`exit`), тож `late` на RP2040 тепер 2.

## 4. Відповіді на відкриті питання плану

| Питання (`docs/day-005.md`, розділ 7) | Відповідь |
|---|---|
| Як Betaflight показує Status у ST/EV | **байт status десятковим числом**: прапорці в бітах 7–5 і max stress у бітах 3–0 разом (75 = `0x4B`, 206 = `0xCE`) |
| Які літери Type для напруги, status, debug | **`RTVCS`**: R — оберти, T — температура, V — напруга, C — струм, S — status. Для debug окремої літери немає (п'ять позицій) |
| Чи DBG3 — це stress | не перевірено: stress ми не шлемо, DBG3 = 0 |
| Чи впливає VCC з EDT на напругу батареї у FC | не перевірено |
